# Team

Everyone on the research pipeline has a file in this folder. Adding yours is your first pull request.

## Add yourself (no installs needed)

1. On the repo page, click **Add file → Create new file**.
2. Name the file `team/<your-github-username>.md` (for example `team/karnatigagan.md`).
3. Copy the template below into it and fill it in.
4. Click **Commit changes**, choose **Create a new branch for this commit and start a pull request**, then **Propose changes** and **Create pull request**.
5. Ask someone else to review it. They go to **Files changed → Review changes → Approve**, then click **Squash and merge**.
6. Review someone else's PR the same way.

If GitHub says the branch is out of date, click **Update branch** first. That's normal when lots of people are merging.

## Template

```markdown
# Your Name

- **GitHub:** @your-username
- **Team:** collectors / reader / archive / source-curators / research-liaison
- **Year and major:**
- **Experience:** none / some Python / some JavaScript / ...
- **Want to learn:**
- **Something in crypto I find interesting:**
```

Only create your own file. Don't edit anyone else's.
